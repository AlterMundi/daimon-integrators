# Foreground device discovery

`python3 -B tools/device_discovery.py --resource host-cuevanico` reads the existing
installed `/usr/local/bin/daimon-integrators status` exactly once and returns
`dm.integrator-discovery/v1`. Select the actual existing Shared Resources record
for the target; that argument is a caller-attributed association, not an enrollment
or proof of resource ownership. Run through the target's existing authorized owner
route. It accepts no address, credential or command override.

This is an initial usable projection for the foundation's `/integrators`,
`/perceptors` and `/actuators`. It does not implement a literal native Matrix
scope RPC. A device hub is not a being; reachability does not establish the
caller's `/here` or `/realm`, grant remote device rights or identify a human.
Field/Nexus remain the owners of their informational exploration contexts; no
universal realm catalog is added here.

The adapter exposes fresh camera/microphone use observations, bounded system
metrics, the managed phase and the existing compact/expanded panel-view control.
Requested view and observed `ui_compact` remain distinct. It strips process names,
private output paths, remote activity and native conversation data. Device use
never proves recording or a model viewing samples. Positive signal wins over
incomplete coverage; stale/future/incomplete negative data remains unknown.
Missing/refused/malformed owner status returns unavailable with no device claims.

The native status socket limits its response to64KiB and four seconds; this
foreground caller has a six-second process deadline and rejects larger output.
No media acquisition, power/input control, Stop, model call, timer or service is
started. Each invocation prints one bounded report; redirect only to one owning
latest report when retention is needed. Logs should retain selected outcomes,
not an unbounded polling history. An explicit periodic workflow needs its own
existing authority and finite contract; this command installs none.

## Installation and control

The projection is an optional public Python file, with standard-library
requirements only. Install a selected exact revision under the existing operator
code directory with0644mode and traversable public parents. Verify import as the
actual consuming owner; no panel/service restart is needed. Retain one previous
public file for a real upgrade. Removing the helper reverses its installation
and leaves the existing native panel, capture configuration and media untouched.

Listed panel-view commands describe the maintained adapter contract; actual
permission remains the existing owner-only control socket. Use the installed
`daimon-integrators view expanded` or `view compact` only within the human task.
Read status until `ui_compact` observes the selected view. The request ACK and
`compact` alone do not prove that the widget changed. Restore the prior observed
view after a reversible demonstration; never use Stop to hide unrelated activity.
This projection itself executes no listed command. Capture, input, playback and
power controls keep their existing task authority and limits.

Qualification: `python3 -m unittest discover -s tests`. Projection tests cover
stale/future/incomplete observations, positive signal, requested-versus-observed
view and private-field exclusion. Receiving source/hash, a real owner status,
control readback and physical-human acceptance belong in the owning Matrix#437
checkpoint, separately from fixtures. No physical acceptance is inferred here.
