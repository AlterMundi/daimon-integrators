# Integrator development

Read the Matrix foundation before changing ontology. `/integrators` are reachable
perceptor/actuator hubs; they are not beings merely because they host a device UI.
Matrix owns semantic authority; Cluster owns resource lifecycle and observed effects.

Keep device activity separate from managed recording and model perception. Unknown
or stale observation never means inactive. Stop only this application's managed
capture process group. Do not capture media to observe whether devices are in use.
Do not add Matrix attention, model wakeups or automatic recording at startup.

Keep credentials, private endpoints, device serials, deployment bindings and media
outside Git. Record generic qualification in docs, private assignments in Shared
Resources' ignored overlay. Preserve existing SSH, sudo and desktop setup.

Use cargo fmt --check, cargo test --no-default-features and cargo clippy before
shipping. Qualify UI on actual Wayland layer-shell hardware separately from tests.
